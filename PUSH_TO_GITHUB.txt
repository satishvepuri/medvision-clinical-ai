PUSH MEDVISION TO GITHUB

1. On github.com, create a NEW empty repository named:

   medvision-clinical-ai

Do NOT add a README, .gitignore, or license on the GitHub page because this folder already has them.

2. Open this project folder in File Explorer.
3. Click the address bar, type cmd, press Enter.
4. Run these commands one by one:

git init
git branch -M main
git add .
git commit -m "Build MedVision multimodal clinical AI project"
git remote add origin https://github.com/satishvepuri/medvision-clinical-ai.git
git push -u origin main

IMPORTANT:
Never git-add data/raw, model weights, API keys, or .env files.
